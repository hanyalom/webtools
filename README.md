# webtools
Web based tools

A GitHub Pages site. Each tool lives in its own folder under `tools/`; the main `index.html` shows a grid of all tools with an image for each.

Adding a tool: create `tools/<name>/index.html` and `tools/<name>/image.svg`, then add a card to the grid in `/index.html`.

Enable GitHub Pages (Settings → Pages → deploy from the main branch, root folder).
