Video Frame Time Calculator

What this tool does

This tool estimates the time between a visible mouse movement and the resulting visible change on a screen, using a video recording that shows both.

Mark the frame where the mouse first moves and the frame where the screen first responds. The tool converts the difference between those frames into milliseconds using the selected frame rate and slow-motion speed. This is a video-based estimate, not a direct measurement of the computer's input-to-display latency; its precision is limited by the recording's frame rate and by how clearly each event can be identified.

How to use it
  1. Record your test using a smartphone camera (regular or 120 / 240 fps slow motion) or high-speed camera, keeping both the mouse and the screen in the frame.
  2. Perform a fast mouse movement, click, or tap while watching the screen reaction.
  3. Drop the video file into the upload box below, or click Choose video file.
  4. The video's frame rate is automatically extracted from the video file. If needed, you can edit it directly.
  5. Set the Slow-motion speed (default 1 for normal speed, or select 1/2, 1/4, 1/8, 1/16, 1/32, 1/64 if your camera saved high-speed footage as slow motion).
  6. Step frame by frame using the buttons or keyboard arrow keys (← and →) to find the exact frame where the mouse moves. Click 📌 Set Move Event (Frame 1).
  7. Step forward to find the exact frame where the screen responds. Click 📌 Set Screen Change (Frame 2).
  8. The measured latency is calculated and displayed below in milliseconds.
Shortcuts: ← / → = ±1 frame · Shift + ← / Shift + → = ±10 frames · Space = Play / Pause · 1 or M = Set Move · 2 or S = Set Screen Change. Mouse wheel or 2-finger pinch zooms into video; drag with 1 finger/mouse to pan; double-tap to reset.
